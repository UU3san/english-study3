# 英検3級 毎日学習アプリ v11

## 新しく追加した「今日の学習」
毎日、次の5項目を進められます。

1. 単語 約5分
2. 4択10問 約10分
3. 間違い復習 約5分
4. 英作文1問 約5分
5. スピーキング1問 約5分

## 主な機能

- 今日の進捗 0/5 を表示
- 5項目を全部終えると、その日の学習完了
- 連続学習日数を表示
- 日替わりの4択10問
- AIに聞いた選択肢を自動で単語帳に登録
- 単語帳からAIに意味を聞ける
- 間違えた問題だけ再学習
- 日替わり英作文
- 英作文をAIに添削してもらう
- 日替わりスピーキング
- 英語の質問読み上げ
- AIに答え方を聞く
- これまでの全80問・単元別学習もそのまま利用可能

## AI
「あかり社会暗記カード」と同じように、Perplexityを別タブで開いて質問する方式です。
APIキーは不要です。

## GitHub
ZIPを解凍して、`index.html` を今のGitHubリポジトリの `index.html` に上書きしてください。

PCとスマホではブラウザ内の学習記録が別になります。
