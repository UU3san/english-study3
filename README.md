# 英検3級・4級 総合学習アプリ v18

## テスト直前単語を「純粋な単語帳カード」に変更

テスト直前の単語機能から、
- 点数
- 覚えた / まだ
- 正解数
- 結果画面
- 苦手判定
をすべて外しました。

### 使い方
1. 「📚 テスト直前 単語カード」を開く
2. 英単語だけを見る
3. 頭の中で日本語の意味を思い出す
4. カードをタップして意味を確認
5. 「次へ」で次のカードへ

### 操作
- ← 前へ
- カードをめくる
- 次へ →
- 🔀 シャッフル
- 最初から

英検3級 / 4級を切り替えると、その級の単語カードに切り替わります。

「今日の単語」の＋5語追加機能はそのまま残しています。
