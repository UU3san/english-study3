# 英検3級・4級 総合学習アプリ v20

## 今回の修正
問題を解いている途中でも、最初の「今日の学習」画面へ戻れるようにしました。

### 追加した戻るボタン
- 4択問題の上部：🏠 今日の学習へ
- 4択問題の下部ナビ：🏠 ホーム
- 語句整序：🏠 今日の学習へ
- 長文読解：🏠 今日の学習へ
- リスニング：🏠 今日の学習へ

単語・単語カード・英作文・スピーキングには、これまで通り戻るボタンがあります。

途中でホームへ戻っても、その時点では「今日の問題完了」にはなりません。
最後まで終了したときに完了扱いになります。
