# 英検3級・4級 切替学習アプリ v14

上部の「級」から
- 英検3級
- 英検4級
を切り替えて使えます。

## 英検4級
添付された「テスト用紙 2026-09-04.pdf」の
短文の語句空所補充①〜④（40問）を収録しました。

4級でも、
- 正解判定
- 正解の意味
- 他の3つの選択肢の意味
- 選ばない理由
- 間違い問題登録
- 間違いだけ復習
- AIに聞く
- 毎日5語
- 今日の10問
を使えます。

## 3級
これまでの80問と毎日学習機能をそのまま残しています。

## 今後追加可能
添付PDFにはさらに、
- 会話文の空所補充
- 語句整序
- 長文読解
- リスニング
があります。
リスニングはPDFだけでは音声そのものが入っていないため、
音声ファイルまたは利用可能な音源があれば完全対応できます。
