# 英検3級・4級 総合学習アプリ v15

## 新しく追加した学習形式
上部の「学習形式」から切り替えられます。

- 短文
- 会話文
- 語句整序
- 長文読解
- リスニング

## 英検4級
添付された「テスト用紙 2026-09-04.pdf」を基に、以下を収録しました。

- 短文 第1〜4回：40問
- 会話文 第5〜8回：32問
- 語句整序 第9〜12回：24問
- 長文読解 第13〜16回：17問
- リスニング 第17〜25回：教材QRの音声ページへ直接移動

語句整序は、元教材の語句をスマホで順番にタップして英文を完成させる方式に変更しています。

## 英検3級
元の3級教材を基に、
- 短文 第1〜4回
- 会話文 第5〜8回
- 長文読解 第9〜12回
- リスニング 第21〜29回（QR音声）
を利用できます。

3級の元教材には語句整序が収録されていなかったため、
3級の語句整序だけは「追加練習（教材外）」として20問を作成し、
画面にもその旨を表示しています。

## QR音声
QRコードに記録されている旺文社の音声サービスページを、
「🔊 問題音声を聞く」ボタンから直接開きます。

音声ファイルそのものはアプリにコピーしていません。
利用時にはインターネット接続が必要です。

## 既存機能
- 毎日学習
- 毎日5語
- 間違い登録
- 間違いだけ再テスト
- 正解以外の選択肢の意味
- 選ばない理由
- AIに聞く
- 英作文
- スピーキング
- ユーザー別記録

はそのまま残しています。
