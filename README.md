# 英検3級 毎日学習アプリ v13

## 今回の追加
4択問題に答えた後、正解だけでなく、
**正解ではない3つの選択肢もすべて説明**するようにしました。

各選択肢について、
- 英単語・英語表現
- 日本語の意味
- なぜこの問題では選ばないのか
を表示します。

また、正解の語句の意味と「この問題の決め手」も同じ画面に表示します。

### 例
breaks
- 意味：壊す／壊れる
- 選ばない理由：この文では feel fine（元気だ）という表現が必要なので合わない

pulls
- 意味：引く
- 選ばない理由：pulls fine という意味にはならないため選ばない

のように復習できます。
