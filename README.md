# 英検3級・4級 総合学習アプリ v17

## もっと単語を覚える
今日の単語は通常5語ですが、＋5語ずつ最大30語まで増やせます。
「今日の5語に戻す」で戻せます。AIで調べた単語を優先し、足りない分は問題の選択肢や重要単語から補います。

## テスト直前確認単語
10語・20語・30語・全部から選択し、英単語だけを見て意味を高速確認します。
「まだ」にした単語はユーザー別・級別に保存され、次回は優先して出ます。
確認後は「まだ」の単語だけでもう一周できます。

優先順：
- 過去に「まだ」にした単語
- AIに聞いた／自分の単語帳に入った単語
- 4択・会話問題の選択肢
- 英検3級・4級の重要単語
