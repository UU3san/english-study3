# 英検3級・4級 総合学習アプリ v19

## 単語帳カードを全面修正

### 1. 原形（辞書の見出し語）で表示
問題に `breaks` と出ていても、単語カードでは **break** と表示します。
同様に、三単現・過去形・進行形・複数形・比較級などを見直しました。

例：
- breaks → break
- feels → feel
- means → mean
- decided → decide
- made → make
- went 等の活用形は、単独カードになる場合は原形へ
- activities → activity
- tickets → ticket
- earlier / earliest → early
- better / best → good / well

会話の決まり文句など「語句として覚えるもの」は、その表現のまま残します。

### 2. 合っている / 分からない
カードごとに
- ○ 合っている
- ？ 分からない
を登録できます。ユーザー・級ごとにブラウザ内へ保存します。

### 3. 分からないだけフィルタ
「分からないだけ：ON」にすると、`？ 分からない` と登録したカードだけ表示します。
その中で「合っている」に変更すると、フィルタから外れます。

### 4. 30語ずつのグループ
カードが多いため、
- 1〜30語
- 31〜60語
- 61〜90語
…
のように自動で30語ずつに分けます。
