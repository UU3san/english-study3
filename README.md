# 英語問題集 v10（あかり社会暗記カード式AI）

## 今回の変更
「あかり社会暗記カード」で使っていたAIの方式に合わせました。

### 問題を解く前
各選択肢の「🤖 AIに聞く」を押すと、その語句についてAIに質問します。
正解は教えないように指示しています。

### 問題に答えた後
「🤖 AIに詳しく聞く」を押すと、問題・全選択肢・自分の答え・正解をAIに渡します。

AIには最初に「問題文のどこが決め手なのか」を説明させ、
そのあと、なぜ正解なのか、全文訳、文法・熟語、
他の選択肢がなぜ違うのか、入試での見分け方・覚え方まで説明させます。

## AI
「あかり社会暗記カード」と同じように Perplexity を開く方式です。
APIキーは不要です。
