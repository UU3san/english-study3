# 英語問題集 v8（AI質問対応）

## 追加した機能

### 選択肢の意味をAIに聞く
各選択肢の横（スマホでは下）に「AIで意味」ボタンを追加しました。

ボタンを押すとChatGPTが開き、以下を質問します。
- 単語・語句の意味
- 品詞
- 問題文の中での意味
- 中学生向け例文
- 覚え方

意味を聞く段階では、AIに「正解は教えないで」と指示しています。

### 回答後の詳しい解説
回答すると、これまでの基本解説に加えて
「AIでさらに詳しく解説」ボタンが表示されます。

ChatGPTには以下を質問します。
- 全文の日本語訳
- なぜ正解なのか
- 文法・熟語・文脈
- 他の3選択肢の意味
- 他の3つがなぜ不正解なのか
- 入試での見分け方・覚え方
- 類題1問

## GitHub Pages
`index.html` を今のGitHubリポジトリの `index.html` に上書きしてください。

## AIについて
APIキーはHTMLに入れていません。
「AIで意味」「AIでさらに詳しく解説」を押すと、ChatGPTを別タブで開いて質問します。
GitHub Pagesだけで安全に使える方式です。
